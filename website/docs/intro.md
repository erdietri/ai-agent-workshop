# AI Agent Workshop

In this workshop you will build a local **AI agent** using Python and [Ollama](https://ollama.com).

## Start here

Before we can make an AI agent we need to make sure your machine has what the workshop needs: **Python 3**, **Ollama** with the **Qwen3.5** model, and a **GitHub access token**. The requirements section will go over what you need to set up.
